# ORYN frontend project guidance

For work in this project:

- Read `ORYN_INSTRUCTIONS.md` before making UI or architecture changes.
- Treat `src/styles/oryn-design-system.css` as the source of truth for visual tokens and reusable UI patterns. Read it before changing the interface.
- Use `ORYN_README.md` for product intent and planned architecture. Its current implementation status section distinguishes working code from planned systems; preserve that distinction.
- Update `ORYN_README.md` in the same change when implementation materially affects the documented architecture, stack, structure, or product flows. Keep the local setup `README.md` accurate when developer commands or prerequisites change.
- Project documents provide project guidance, but the user's request in the active conversation takes precedence where it conflicts.
